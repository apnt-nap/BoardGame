### For the report (facilitator notes)

- **Believability score** = average of statements 1 and 3. Target: **4.0 or higher**.
- **Readability score** = statement 2. A score near 3 is ideal: the Knight should feel learnable but not fully predictable.
- **Replay intent** = statement 4.
- Ask each tester to keep the file `knight_log.txt` from their run (the path is shown on the end screen). Pick 2–3 logged decisions that match the tester's "surprise" story and quote them in the report as evidence that the behaviour came from the AI's rules, not from chance.
